# Changelog

## 1.0.0

Initial public release.

- One guided `START_HERE.bat` workflow.
- Recursive ZIP and TAR-family source extraction, including nested archives.
- Portable configuration with no personal source or tool paths.
- Isolated Sphinx/documentation environment.
- Compatible Visual Studio/MSBuild and legacy WiX prerequisite checks.
- Optional CPython regression tests and copied HTML documentation.
- Advanced troubleshooting commands organized under `advanced_tools`.
- MIT licensing under KittensX.
- CPython test-marker branding disabled by default.
- Release-style installer version text enabled by default.
