supporting documentation. It does not need to bundle a particular CPython
source release.

Users select or provide their own compatible CPython source archive.

If a future release of this repository directly includes CPython source code,
compiled Python binaries, generated Python documentation, or third-party
runtime components, the corresponding license and notice files must be included
with that release.

## Recommended files for generated installer releases

When publishing an independently built CPython installer, include:

```text
LICENSE-PYTHON.txt
THIRD_PARTY_NOTICES.md
BUILD_INFORMATION.md
SHA256SUMS.txt
```

`LICENSE-PYTHON.txt` should be copied from the exact CPython source release used
for the build rather than recreated from memory.

`BUILD_INFORMATION.md` should identify:

- The CPython version
- The source release or source commit
- Whether CPython was modified
- A brief summary of modifications, when applicable
- The CPython Installer Builder version
- The target architecture
- The Windows and toolchain versions used
- The build date
- A statement that the installer is an independent build
- The installer checksum

## Recommended notice inside an independent installer release

```text
This package contains an independently built distribution of CPython.

CPython is developed by the Python Software Foundation and its contributors
and is licensed under the Python Software Foundation License Version 2.

This installer is not an official python.org release and is not affiliated
with or endorsed by the Python Software Foundation.

See LICENSE-PYTHON.txt and THIRD_PARTY_NOTICES.md for applicable terms and
attributions.
```

## Display requirements

A graphical splash screen or permanent on-screen Python notice is not generally
required merely because an application was written in Python.

However, when an application or installer redistributes the CPython runtime,
the applicable CPython license, copyright notice, and incorporated third-party
notices should remain available in the distributed package or accompanying
materials.

Suitable locations can include:

- A license file installed with the application
- An installer license or notices page
- An About or Legal Notices screen
- Documentation included with the download
- A notices directory beside the distributed binaries

The notices should remain accessible after installation.
